# grokhunter-plugin-lab

GrokHunter lab: Grok Build plugin install and marketplace add on the phone lab.

## Install (from this marketplace)

```bash
grok plugin marketplace add FineComputer14451/GrokHunter
grok plugin install grokhunter-plugin-lab --trust
```
