# grokhunter-hooks

GrokHunter lab: User hooks JSON and /hooks for Grok Build on GrokHunter.

## Install (from this marketplace)

```bash
grok plugin marketplace add FineComputer14451/GrokHunter
grok plugin install grokhunter-hooks --trust
```

## Components

- Skills: `hooks-lab`
- Agents: `hook`
- Commands: _none_
