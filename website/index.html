Features

Everything for an on-device coding agent

 

Rootless first

Termux + proot only. Stock Android, warranty intact — no Magisk, recovery, or firmware modules.

Grok as on-device agent

Official Grok Build CLI with compact TUI, headless one-shots, and plan mode tuned for mobile.

Real Linux toolchains

Full Kali apt: gcc, python, node, rust, go — a real coding lab, not a toy shell.

Desktop via Termux:X11

XFCE + low-latency nh-x11 helper for editors and browsers that feel like a mini workstation.

Doctor & status

grokhunter doctor checks binary, PATH, secrets, DNS, and NetHunter packages in one report.

Overlay, not a fork

Sits on top of the official NetHunter rootfs. Idempotent install, clean uninstall, modular lib/.

Install

One command, modular stack

Requires Termux from F-Droid or GitHub, Android 8+, aarch64 recommended, and SuperGrok / X Premium+ or an XAI_API_KEY for Grok Build.

01 One-liner 
bash <(curl -fsSL https://raw.githubusercontent.com/FineComputer14451/GrokHunter/main/install.sh)
02 Recommended full stack 
bash install.sh --full --de xfce --browser chromium --with-grok --with-x11
03 Or clone 
git clone https://github.com/FineComputer14451/GrokHunter.git
cd GrokHunter
bash install.sh

Installer flags

  • -f, --fullFull installation (includes desktop)
  • -m, --miniMini (essential packages)
  • -n, --nanoNano (minimal footprint)
  • --de e17 | gnome | i3 | kde | lxde | mate | xfce
  • --browser chromium | firefox | both
  • --with-grokInstall native Grok Build CLI
  • --with-x11Install Termux:X11 + nh-x11 helper
  • --no-de / --no-grok / --no-x11Skip those stages

After install

  • nethunter — enter Kali shell
  • nh-x11 — low-latency desktop
  • grok — Grok Build TUI
  • grokhunter doctor — health report
